STEP 1 — ONE-TIME SETUP (PowerShell)
------------------------------------
Open PowerShell, then:

  git clone https://github.com/Sarfaraz021/linkedin-graphrag-pipeline.git
  cd linkedin-graphrag-pipeline

  py -m venv .venv
  .\.venv\Scripts\Activate.ps1

If activation is blocked, run once:
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

  pip install -r requirements.txt
  pip install openpyxl requests pandas

  copy .env.example .env

Open .env in Notepad and set:
  HARVEST_API_KEY=your-harvest-api-key-here


STEP 2A — RESUME (recommended)
------------------------------
Ask Sarfaraz to zip and send:

  linkedin scraper\output\manifest.json
  linkedin scraper\output\profile_cache.json
  linkedin scraper\output\structured\7470376778100834304.json

Unzip into the same folders in your clone.

Then in PowerShell (venv activated):

  cd linkedin-graphrag-pipeline
  $env:HARVEST_API_KEY = (Get-Content .env | Where-Object { $_ -match '^HARVEST_API_KEY=' } | ForEach-Object { $_ -replace '^HARVEST_API_KEY=','' })
  python "linkedin scraper\main.py" `
    --api-key $env:HARVEST_API_KEY `
    --excel "data\Urls\Linkedin saved posts.xlsx" `
    --output-dir "linkedin scraper\output" `
    --max-urls 20 `
    --skip 23 `
    --enrich `
    --enrich-mode basic

Manifest skips URLs already scraped. Post 1 reuses cached data.
